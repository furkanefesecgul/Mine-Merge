# Mine-Merge
KBE Games olarak bağımsız oyun geliştirme yolculuğumuz kapsamında geliştirdiğimiz mobil oyunlarımızdan biri olan Mine Merge, Mayıs 2026 itibarıyla Google Play'de oyuncularla buluşmuştur. Mine Merge ile oyunculara keyifli, sürükleyici ve eğlenceli bir mobil oyun deneyimi sunmayı hedefliyoruz.
